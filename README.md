# Linux System Report

A Bash script that generates a readable Linux system report, including system information, disk usage, memory usage, and service status.
## Features

- Date
- Current User
- Hostname
- Kernel Version
- Uptime
- Disk Usage
- Memory Usage
- Service Status
- Active Network 

## Technologies

- Bash
- awk
- systemctl
- df
- free

## Usage

```bash
chmod +x system_report.sh
./system_report.sh
```
